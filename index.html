🔐 Connect to GitHub

This app saves your shopping list to your GitHub repo so I (in chat) can see it too.

One-time setup:

  1. Tap → github.com/settings/personal-access-tokens/new
  2. Token name: DE Outlet Tracker
  3. Expiration: 7 days (or whatever you want)
  4. Repository access: Only select repositories → choose de-shopping
  5. Repository permissions: Contents → Read and write
  6. Bottom: Generate token → copy the long string starting with github_pat_
  7. Paste it below

Classic tokens (ghp_…) also work — generate one at github.com/settings/tokens with the repo scope.
